使用说明 对于有提供支持的 API 的用户：
  1. 填写 API 配置并保存。密钥仅保存在当前页面内存中，刷新页面后需要重新填写。
  2. 上传旧版英文文件（仓库中的 原语言文件备份/strings.json）、新版英文文件（对应 GitKraken 版本安装目录中的 strings.json）和旧版翻译文件（仓库中的 strings_x.x.x.json）， 然后点击 [对比] 获取差异内容。
  3. 点击 [自动翻译]。翻译期间按钮会显示“翻译中...”并暂时禁用；完成后页面会显示“翻译并整理完成。”。
  4. 导出并覆盖 strings.json 文件。
  5. 重启 GitKraken。
对于没有 API 的用户：
  1. 上传旧版英文文件（仓库中的 原语言文件备份/strings.json）、新版英文文件（对应 GitKraken 版本安装目录中的 strings.json）和旧版翻译文件（仓库中的 strings_x.x.x.json）， 然后点击 [对比] 获取差异内容。
  2. 复制文本框中的内容，使用其他翻译工具完成翻译。
  3. 将翻译后的内容使用 格式化工具 整理为有效 JSON。
  4. 将整理后的内容导出或复制为 strings.json，并覆盖 GitKraken 安装目录下的同名文件。
  5. 重启 GitKraken。
可能出现的问题和解决建议 报告问题
  1. 使用 API 翻译后没有生成新增内容：
    • 确认页面通过 GitHub Pages 或本地 HTTP 服务打开。直接以 file:// 打开页面时， OpenAI 和 DeepSeek 的跨域请求可能失败。
    • 检查 API 是否正确配置（有效性、模型访问权限等）。
    • 检查页面错误信息和当前选择的模型是否可用。
  2. 按下[自动翻译]后看起来没有反应：
    • 如果按钮显示“翻译中...”并处于禁用状态，说明翻译任务正在执行，请等待完成或错误提示。
    • 如果按钮没有进入该状态，请检查 API 配置是否完整。
  3. 页面显示翻译失败或结果不完整：
    • 页面会显示翻译服务的具体错误信息，并按批次自动重试一次。重试后结果数量仍不完整时， 会停止生成，避免输出部分未翻译的内容。
    • 检查 API 配置、余额、模型访问权限和网络连接。
    • 如果选择的是有道 API，请检查请求是否超时或返回了错误码。
    • 如果选择的是 DeepSeek API，请检查 DeepSeek 官网 - 产品 - 服务状态， 或稍后重试。
    • 如果问题持续存在，请携带页面错误信息和所用模型报告问题。
OpenAI API 的申请步骤
  1. 进入 OpenAI 官方网站。
  2. 注册或登录。
  3. 在顶栏左上角新建 Project（可选）或使用用户密钥（可选，不推荐），之后在顶栏右上角选择“Dashboard”，随后侧边栏选择“API Keys”。
  4. 通过“+ Create New secret key”按照提示新建一个密钥。
  5. 请保管好您的密钥。平台将不会再次展示您的密钥， 忘记则意味着您需要重新创建密钥并删除旧的密钥。
  6. 复制以 sk- 开头的 API 密钥到配置中。填写后页面会自动获取可用模型； 默认模型不可用时会选择接口返回的首个可用模型。可根据页面显示的价格档位选择模型。

DeepSeek API 的申请步骤
  1. 访问 DeepSeek API 开放平台。
  2. 注册/登录后进入 API keys 管理页面。
  3. 点击“创建 API key”生成新密钥。
  4. 请保管好您的密钥。平台将不会再次展示您的密钥， 忘记则意味着您需要重新创建密钥并删除旧的密钥。
  5. 复制以 sk- 开头的 API 密钥到配置中。

有道 API 的申请步骤
  1. 进入 有道智云控制台。
  2. 注册或登录。
  3. 在侧边栏选择“自然语言翻译服务/文本翻译”。
  4. 找到“文本翻译/应用概览/创建应用”。
  5. 创建应用并复制 AppKey 和 AppSecret 到配置中。
